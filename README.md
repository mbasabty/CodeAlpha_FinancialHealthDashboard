# Financial Health Dashboard

An interactive Power BI dashboard designed to analyze and optimize HR processes and workforce management. The dashboard provides actionable insights into recruitment performance, employee turnover, employee satisfaction, workforce performance, and future hiring needs through predictive analytics.

## Live Demo

**Dashboard Website:**  
https://mbasabty.github.io/CodeAlpha_FinancialHealthDashboard/

---

## Project Objective

Create a dashboard to analyze and optimize HR processes and workforce management by:

- Tracking recruitment metrics and employee turnover rates.
- Analyzing employee satisfaction and performance data.
- Implementing predictive analytics for forecasting hiring needs.
- Supporting data-driven HR decision-making.

---
## Dashboard Pages

1. Key indicators
2. Income Statement
3. Balance Sheet
4. Cash Flow
5. Forcast

## Technologies Used

- **Power BI** – Data Visualization & Reporting
- **Power Query** – Data Cleaning & Transformation
- **DAX** – KPI and Metric Calculations
- **Excel / CSV Datasets** – Data Sources
- **Predictive Analytics Models** – Workforce Forecasting

---

## Key Performance Indicators (KPIs)

- Total Revenue
- Total Expenses
- Net Income
- Avg Assests
