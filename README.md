# HR Analytics Dashboard

An interactive Power BI dashboard designed to analyze and optimize HR processes and workforce management. The dashboard provides actionable insights into recruitment performance, employee turnover, employee satisfaction, workforce performance, and future hiring needs through predictive analytics.

## Live Demo

**Dashboard Website:**  
https://mbasabty.github.io/CodeAlpha_FinancialHealthDashboard/

---

## Project Objective

Create a dashboard to analyze and optimize HR processes and workforce management by:

- Tracking recruitment metrics and employee turnover rates.
- Analyzing employee satisfaction and performance data.
- Implementing predictive analytics for forecasting hiring needs.
- Supporting data-driven HR decision-making.

## Key Features

### Recruitment Analytics
### Employee Turnover Analysis
### Employee Satisfaction & Performance
### Predictive Workforce Analytics

## Dashboard Pages

### 1. Executive Overview
Provides a high-level summary of key HR metrics including:
- Total Employees
- New Hires
- Employee Turnover Rate
- Employee Satisfaction Score
- Average Performance Rating

### 2. Recruitment Dashboard
Visualizes:
- Recruitment trends
- Hiring funnel performance
- Candidate conversion rates
- Time-to-hire metrics

### 3. Workforce Analytics
Displays:
- Employee distribution
- Department-level insights
- Workforce demographics
- Retention statistics

### 4. Performance & Satisfaction
Analyzes:
- Employee performance ratings
- Satisfaction trends
- Department comparisons
- Workforce engagement indicators

### 5. Predictive Analytics
Provides:
- Hiring forecasts
- Attrition predictions
- Workforce planning insights
- Future staffing recommendations

## Technologies Used

- **Power BI** – Data Visualization & Reporting
- **Power Query** – Data Cleaning & Transformation
- **DAX** – KPI and Metric Calculations
- **Excel / CSV Datasets** – Data Sources
- **Predictive Analytics Models** – Workforce Forecasting

## Key Performance Indicators (KPIs)

### Recruitment KPIs
- Total Applicants
- Total Hires
- Hiring Rate
- Time-to-Hire
- Recruitment Efficiency

### Employee KPIs
- Employee Satisfaction Score
- Performance Rating
- Employee Engagement Index
- Average Employee Tenure

### Retention KPIs
- Employee Turnover Rate
- Retention Rate
- Voluntary Attrition
- Involuntary Attrition

### Forecasting KPIs
- Predicted Hiring Demand
- Expected Attrition
- Workforce Growth Forecast
- Staffing Requirements

3. Navigate through dashboard pages.
4. Use filters and slicers to explore data.
5. Analyze KPIs and trends to support HR decisions.
